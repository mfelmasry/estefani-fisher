# Estefani Fisher

Un lugar para escribir, leer y respirar. Sitio de bienestar emocional en español: cartas, historias, biblioteca, podcast, diario privado y un espacio para terapia.

Inspirado en [ivettefisherterapia.com](https://ivettefisherterapia.com).

## Cómo correrlo

Necesitas Node.js 18 o superior.

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173).

```bash
npm run build    # producción
npm run preview  # vista previa del build
```

## Qué incluye

- **Inicio** — pregunta del día, carta destacada, podcast y momentos de vida
- **Cartas** — textos para leer despacio, con opción de guardar
- **Historias** — experiencias compartidas, con nombre o en anónimo
- **Biblioteca** — organizada por relaciones, familia, trabajo, autoestima, ansiedad, cambios, duelo y propósito
- **Podcast** — episodios para escuchar sin prisa
- **Comunidad** — un espacio sin likes ni competencia
- **Terapia** — proceso, citas (Calendly) y contacto
- **Escribir / Diario / Mi camino** — escritura privada en el navegador
- **Entrar / Crear** — correo o continuar con Google, Microsoft, Apple o Facebook (sesión local)

El diario, las cartas guardadas y la sesión se guardan en `localStorage`. No hay backend todavía: el inicio con Google, Microsoft y el resto es una interfaz de demostración.
